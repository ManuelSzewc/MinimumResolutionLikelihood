# MinimumResolutionLikelihood
Public repository for the Minimum Resolution Likelihood paper.

The repository contains three files that should reproduce all results, once linked with [HI-SIGMA](https://github.com/OzAmram/HI-SIGMA/tree/main). The files are

# Toy model

There are two files
- `mrl_abstract_functions.py` contains all necessary functions to run the toy model pseudo-experiments and MRL fits.
- `run_toy_model.ipynb` runs all pseudo-experiments contained in this paper.

# HI-SIGMA

`run_hi_sigma.ipynb` runs all pseudo-experiments for the HI-SIGMA case. It should be linked against the `HI-SIGMA` code and the [di-Higgs dataset].
